# 0.3.0 验证记录

日期：2026-11-16。验证对象为独立 CC Switch Android 工程。

## 已验证

- TypeScript 类型检查；65 项配置/MCP/技能/会话/用量/模型目录测试通过。结果见交付日志。
- Java 事务测试 16 项：版本冲突、读回核验、失败恢复及不覆盖外部更改。
- 9 项 Android 主机单元测试通过：历史推理过滤、顶层 ID 白名单、call_id/嵌套 ID/本轮 effort 保留、拒绝不安全上下文、gzip/zstd、分块输入、SSE、HTTP 429 原样返回、POST 不重试。使用本机 socket 模拟供应商，无收费 API 请求。
- Android release lint、编译、APK 签名与 manifest/权限检查；最终日志随 APK 交付。
- 生产前端在 360×792（DPR 4 / 1）与 360×430 深色触控视口：完整表单与后台提示、完整会话分组和阅读器、完整用量指标/趋势/表格。使用 tests/browser-fixture.js 合成数据；未冒充 SAF。

## 待实机验证

- 系统 DocumentsUI 的 Codex 根目录是否可选；持久授权、撤权、设备重启后的真实 ContentResolver 行为。
- Codex 宿主与 CC Switch 是否共享 127.0.0.1 网络；一加后台策略、锁屏长时间 SSE、通知授权返回、强杀/重启后的恢复。
- 原生 ARM64 zstd 解码库在设备运行、16 KiB 页面装载及 gzip/br/zstd 实际 Codex 请求。
- config.toml 与模型目录写后真实读回，MCP/工作目录/项目配置保留；完全重启 Codex 后实际调用所选供应商。
- 键盘弹起、深色/系统主题、不同缩放与高 DPI 下的触控体验。

**浏览器合成数据、主机测试、可安装 APK 均不等于“普通 SAF 目录实机读写通过”或“已接通 Codex”。这两项当前尚未验证。**

## 已知限制

完整 UI 不表示所有桌面后端均已移植。原生 Responses 以外协议转换、宿主钥匙串/OAuth、会话删除/终端启动、图片文件读取需要进一步实现。会话与用量读取有边界，继承历史基线无法确认时暂缓统计；费用为估算。前台服务不能承诺进程永不被系统停止。
