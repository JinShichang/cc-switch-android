# 0.3.1 验证记录

日期：2026-11-16。测试独立 CC Switch Android 工程；手机截图来自用户，以下新增验证在主机/浏览器执行。

## 已验证

- 79 项 TypeScript 回归测试：配置保护、认证兼容、模型目录、上游用量快照去重/配对、续写和父历史重放、时间单位、未知累计基线不重复统计。
- Java 事务测试 16 项：版本冲突、写后核验、失败恢复、不覆盖外部更改。
- Android 主机单元测试 18 项：原有历史过滤/HTTP 流转 9 项，SessionLogReader 9 项；覆盖完整尾行、未完成尾行、异常行、边界、Zstandard、损坏压缩、ordinal 和限额来源字段。
- 生产前端在 360×792、DPR 4 的浅色触控视口：32 行 TOML 输入、滚动、长地址换行、保存后重新打开完整末尾、非法 TOML 明确提示；四个模型字段标签与思考菜单可见。
- 360×430 深色触控视口和 360×792 浅色视口：合成原生桥接数据（5 份日志，完整记录外附尾行/异常标记）显示 5 条请求、7,000 Tokens、45.5% 缓存命中、趋势与明细；重复同步不翻倍。
- Release 编译、lint 与原签名校验日志随交付提供，使用已有缓存增量构建。
